SpringBall

Klassen har en lidt speciel constructor. Hvad betyder linjen

Hvad er forholdet mellem this.start og this.maxDragDist?

this.start = createVector(x, y)
this.maxDragDist = maxDragDist

Forklar metoden drag() linje for linje

drag(){
  var mouse = createVector(mouseX, mouseY)
  mouse.sub(this.start)
  if(mouse.mag() > this.maxDragDist) mouse.setMag(this.maxDragDist)
  this.position = this.start.copy()
  this.position.add(mouse)
  this.isDragging = true
}

Forklar metoden launch() linje for linje

launch(){
  this.velocity = this.start.copy()
  this.velocity.sub(this.position)
  this.velocity.mult(0.15) // 0.15 dæmper farten, så bolden ikke flyver for hurtigt
  this.isFlying = true
  this.isDragging = false
}

Forklar metoden update

update(){
  if(!this.isFlying) return
  this.velocity.add(gravity)
  super.update()
}

countHit

Når to bolde rammer hinanden, har vi brug for en måde at tælle ET point. Klassen Ball har metoden hit(anotherBall), som alle andre bolde nedarver. Den returnerer true, hvis den anden bold er inden for dens radius. Koden ser sådan her ud:

myClasses.js

hit(anotherBall){
  var b = anotherBall
  var totalR = (this.diam + b.diam) / 2
  var d = dist(this.position.x, this.position.y, b.position.x, b.position.y)
  return d <= totalR
}

Men hit() er sand i hvert eneste frame, så længe de to stadig overlapper. Hvis vi tæller dér, får vi mange point for ét sammenstød. Derfor har skitsen countHit, som tager begge instanser og holder øje med, om de allerede rørte hinanden i forrige frame:

index.js

countHit(spring, other)

function countHit(a, b){
    var h = a.hit(b)
    if(h && !a.wasHit){
        hits++
        select('#g-points').html(hits)
    }
    a.wasHit = h
}

function steer(b){
    if(keyIsDown(65)) b.left()
    if(keyIsDown(68)) b.right()
    if(keyIsDown(87)) b.up()
    if(keyIsDown(83)) b.down()
    if(keyIsDown(UP_ARROW)) b.forward()
    if(keyIsDown(DOWN_ARROW)) b.back()
}

function clearDrive(b){
    if(keyIsDown(UP_ARROW) || keyIsDown(DOWN_ARROW)){
        b.didBounce = false
        return
    }
    if(b.didBounce) return
    b.velocity.set(0, 0)
}

MovingBall — sammenslået

I skal lave et flowchart til en ShootingBall. Den er mage til MovingBall, men har det ekstra lag at den hele tiden vedligeholder sit array med bullets. De bullets skal passes som en del af dens livscyklus.

I hvert frame gør ShootingBall det samme som MovingBall. Derudover løber den bullets igennem: opdaterer hver enkelt, lader dem bounce, og fjerner dem der er væk. Hvis der skydes, kommer der en ny bullet på arrayet.
